# GUI_based_QRCODE_GENERATOR
A simple and interactive Python GUI application built with Tkinter and Pillow to generate customized QR codes with a custom background image.
A user-friendly Python GUI application that generates customized QR codes instantly with support for background images.

## Features
- Interactive desktop GUI built using **Tkinter**.
- Custom styling and background image support powered by **Pillow (PIL)**.
- Fast and reliable QR code generation using the **qrcode** library.
- Saves generated QR codes automatically to your local storage.

## Tech Stack
- **Python 3.x**
- **Tkinter** (Standard GUI Library)
- **Pillow (PIL)** (Image processing)
- **qrcode** (QR code generation)
